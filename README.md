# Q F&B OS

**The live operating system for hospitality.**
*Powered by Quantum Climb*

## Stack
- React
- Vite
- TypeScript
- Tailwind CSS
- Supabase (Backend Architecture)

## Local Setup
```bash
npm install
npm run dev
```

## Current Backend Status
The dedicated Q F&B OS Supabase backend has NOT yet been remotely activated.
The application currently uses local fixture services or local Supabase implementation stubs.

Please refer to [docs/DEVELOPER_HANDOFF.md](docs/DEVELOPER_HANDOFF.md) for the exact development status and next steps before activating the backend.
